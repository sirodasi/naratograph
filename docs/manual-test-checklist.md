# 実地テストのチェックリスト（PR #2）

自動テスト（`npm run test:run` の単体テスト、`npm run test:rules` のルールのテスト）では確かめられない、**複数のアカウント・複数のタブ**での動きを確かめる手順です。

## 準備

1. Firebase コンソールで、自分の UID を `admins/{uid}: true` に入れる（プロフィールの「アカウント」タブに UID が出ます）。
2. ルールを反映する: `firebase deploy --only database`（[firebase-security-rules.md](firebase-security-rules.md)）。
3. ブラウザを 2 つ用意する（例: 通常ウィンドウ = GM、シークレットウィンドウ = 別の Google アカウントの PL）。PL を 2 人にできると応援も試せます。
4. 秘匿の確認用に、**後続クエスト（unlockType: quest）と敵つきのクエスト**を含むシナリオを用意する。

## 1. 権限

- [ ] `admins` に入っていないアカウントでは部屋を作れない。
- [ ] PL の画面にフェイズを進めるボタンが無い。PL がコンソールから `state/sessionPhase` を書くと拒否される。
- [ ] 退室して入り直しても、PL の役割（role）が GM にならない。

## 2. シナリオの秘匿と真相の承認

- [ ] PL の画面には未登場のクエスト、真相、クエストの敵が出ない。
- [ ] PL がクエストを解決すると、GM の画面上部に「公開する」と「すべて公開する」が出る。承認するまで PL には真相が出ない。
- [ ] 承認すると、PL に真相が出て、後続クエストが登場する。
- [ ] 承認の直後の後続クエストは「GM の確認待ちです」と表示され、少し待つと戦闘を始められる。
- [ ] 「以後は自動で公開する」をオンにすると、以後は承認なしで公開される。
- [ ] 承認した直後に GM が ↩（取り消し）を押すと、真相が隠れ、後続クエストも消える。
- [ ] **GM が 2 つのタブで開いた状態で**、一方で承認し、もう一方で取り消すと、記録が復活しない（後続クエストが戻ってこない）。
- [ ] 承認した直後に GM のタブを再読み込みしても、確認待ちのまま残らない（数秒で解除される）。

## 3. PL が始めるクエスト戦闘

- [ ] PL が敵つきクエストの戦闘を始めると、敵が入るまで待機の画面になり、GM の画面が開いていれば自動で敵が入る。
- [ ] 敵が設定されていないクエストでは、戦闘が中止されて元のシーンに戻る。

## 4. 同時更新

- [ ] GM と PL がほぼ同時に操作しても（例: GM がリソースを変えるのと同時に PL がアイテムを使う）、どちらの変更も消えない。
- [ ] 回線を切って（DevTools の Offline）戻すと、上部の切断表示が出て消え、オンライン表示（緑の点）が戻る。

## 5. GM の要求（ダイス・選択・お知らせ）

- [ ] 目標値つきのダイス要求を出すと、PL の画面下にカードが出る。振った後、同じスポットの別の PL に応援のカードが出て、応援のダイスが足される。判定役が「確定」する。
- [ ] 独自の表を使ったダイス要求で、「渡す」設定の表なら、出たアイテムが振った PL に一度だけ渡る。
- [ ] オフラインの PL の分を、GM が代わりに振ったり確定したりできる。

## 6. プロット配置（追加ルール）

- [ ] 両者が秘密に初期位置を選び、全員が選んだところで同時に公開される。PL から相手の選択は見えない。
- [ ] 公開の前に PL が切断した場合、GM の「未公開の参加者を乱数で配置して開始」で進められる。

## 7. 弾幕ごっこの演出

- [ ] 被弾すると画面が揺れ、マスにリングと破片が出る。残り人数が 0 になると KO の演出が出る。
- [ ] スペルカードを宣言するとカットインが出る（PC は左から青、敵は右から赤、最終戦は金）。タップで飛ばせる。
- [ ] 回避の残像やグレイズの「GRAZE +N」が出る。
- [ ] 🎬 で動きを抑えると、揺れとマスの演出が止まり、カットインは静止表示になる。

## 8. 異変再現のプリセット

- [ ] プロフィールの「異変再現」タブで、プリセットを作成、編集、複製、削除できる（組み込みを雛形にできる）。
- [ ] JSON で書き出したものを読み込むと、編集画面で中身を確認してから保存できる。
- [ ] セッション中の「独自」タブで適用すると、定義が追加される。外すと、そのプリセットの定義だけが消える。

## 9. スマートフォン

- [ ] 幅 820px 以下で、右パネルがドロワーになる。自分の手番になると自動で開く。
- [ ] GM のパネル（GM タブ、独自タブ、盤面編集、GM 編集）のボタンが押しやすい大きさで表示される。

## 10. 終了

- [ ] GM が終了ボタンを押すと、ログ（.txt）が書き出され、全員がロビーに戻り、部屋が消える。
- [ ] GM が他の PL の成長を適用した場合、その PL の画面を開いたときに成長が保存される（保存されるまで GM の終了確認に警告が出る）。
